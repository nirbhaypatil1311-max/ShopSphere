# 🛒 ShopSphere

ShopSphere is a full-stack e-commerce web application built using modern
JavaScript technologies.

## 🚀 Features

### Customer Features

- User registration and login
- JWT authentication
- Product browsing
- Product search
- Category filtering
- Price filtering
- Product sorting
- Product details
- Shopping cart
- Quantity management
- Wishlist
- Checkout
- Shipping address
- Order placement
- Order history
- Order details
- User profile

### Admin Features

- Admin authentication
- Admin dashboard
- Product management
- Add products
- Edit products
- Delete products
- Category management
- View customer orders
- Update order status
- Stock management

## 🛠️ Technologies

### Frontend

- Next.js
- React
- JavaScript
- Tailwind CSS
- Axios
- Context API

### Backend

- Node.js
- Express.js
- JavaScript
- JWT
- bcryptjs
- REST API
- CORS

### Database

- MySQL
